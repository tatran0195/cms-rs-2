### 3. Critical Bug Fix in cms-auth

**File:** `/home/user/cms-rs/crates/cms-auth/src/lib.rs`

**Issue:** The `AuthService::new()` constructor had a critical bug where it tried to use the type `PgPool` as a value:

```rust
// BEFORE (BROKEN)
pub fn new(config: AuthConfig) -> Result<Self, AppError> {
    let encoding_key = EncodingKey::from_secret(config.session_secret.as_bytes());
    let decoding_key = DecodingKey::from_secret(config.session_secret.as_bytes());

    Ok(Self {
        config,
        pool: PgPool, // ❌ This is a TYPE, not a value!
        encoding_key,
        decoding_key,
    })
}
```

**Fix:** Changed to require both config and pool as parameters:

```rust
// AFTER (FIXED)
pub fn new(config: AuthConfig, pool: PgPool) -> Self {
    let encoding_key = EncodingKey::from_secret(config.session_secret.as_bytes());
    let decoding_key = DecodingKey::from_secret(config.session_secret.as_bytes());

    Self {
        config,
        pool,
        encoding_key,
        decoding_key,
    }
}
```

**Impact:** This was a compile-time error that would have prevented the entire project from building.

### 4. jsonwebtoken 9.x Migration

**Files Updated:**

- `/home/user/cms-rs/crates/cms-auth/src/jwt.rs`
- `/home/user/cms-rs/crates/cms-auth/src/session.rs`
- `/home/user/cms-rs/crates/cms-auth/src/lib.rs`

**Changes:** Updated all JWT-related code to use jsonwebtoken 9.x API:

```rust
// BEFORE (jsonwebtoken 0.5)
Header::new(Algorithm::HS256)

// AFTER (jsonwebtoken 9.x)
Header {
    kid: None,
    alg: jsonwebtoken::Algorithm::HS256,
    ..Default::default()
}
```

**Note:** The jsonwebtoken API remains largely compatible, but the Header constructor changed to use struct update syntax.
